# Marriage tab — reference screenshots

Photos of the reference app on an iPhone (notch model), used to compare
against our Marriage tab (`lib/features/marriage/`). Numbered in page order,
top to bottom. Downscaled to 1080 px wide JPEG.

Every screen: top bar = filters icon · "Sort" pill · teal lightning (boost)
button · bell with red dot. Pinned action buttons at the bottom (pass ·
undo · compliment/boost · like) float over the content while scrolling;
bottom nav = Marriage · Explore · Jamaa · Chat · Menu (avatar).
