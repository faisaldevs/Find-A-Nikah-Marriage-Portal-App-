# Feed — decisions

Decided by the product owner on 2026-11-14. These are **final for v1** unless
changed here (with a date).

## Settled

| # | Topic | Decision |
|---|---|---|
| 1 | Approach | Plan the full feature, but deliver in **phases**; ask backend in rounds, not all at once; never break the app; keep a tracker (`PROGRESS.md`) |
| 2 | Anonymous posts | **None.** Every post/comment/like belongs to a real member (removed in the app) |
| 3 | Users | Feed members are the **same users** as Marriage — one account |
| 4 | Name shown | **First name + last initial** (e.g. "Ayat N."); full name never sent to Feed screens |
| 5 | Handle | `@handle` **kept**, **auto-generated by the server**; member cannot choose it |
| 6 | Identity in the app | `userId` everywhere; `handle` is a display label only (links survive handle changes) |
| 7 | Topics | Fixed list managed by admins; one topic per post; "For you" and "New" are feed *modes*, not topics |
| 8 | Groups | **Not in v1** — drop the profile "Groups" tab |
| 9 | Commenting | Anyone who can see a post can comment/reply; **no gender separation** |
| 10 | Block | Uses the **same block list** as Marriage and Chat |
| 11 | Edit / delete | Members can **edit and delete** their own posts and comments; edit time limit **not decided** (backend to propose) |
| 12 | Compose | **Text only** in v1; Photos/Videos/GIFs/Camera stay "coming soon" |
| 13 | Saved posts | **Later.** Hide/"coming soon" the Save row until built |
| 14 | Moderation | **Out of v1** (admin queue, auto-hide, profanity filter — add later if needed) |
| 15 | Notifications | **Out of v1**; the bell stays "coming soon" |
| 16 | Marriage profile from Feed | **Always shown** on the profile's Marriage side; show what the viewer may see and **blur the rest** with a "profile not available for you" message; unlocking may become **paid** later. Locked data must be withheld by the server (see `04_PROFILE_DESIGN.md`) |
| 17 | Backend deliverable | Backend must answer with `FEED_MOBILE_IMPLEMENTATION_PLAN.md` (same pattern as Marriage) |
